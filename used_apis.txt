AUTHENTICATION APIs (Used by All User Types)
==============================================

POST   /api/auth/register/
       Purpose: User registration for customers, service providers, and admins
       Used by: Registration forms in all dashboards
       Features: Account creation with user type selection

POST   /api/auth/login/
       Purpose: User authentication and login
       Used by: Login page for all user types
       Features: Username/password authentication, JWT token generation

POST   /api/auth/forgot-password-clean/
       Purpose: Password reset functionality
       Used by: Forgot password modal in login page
       Features: Generate new password and send via email

GET    /api/auth/me/
       Purpose: Get current user profile information
       Used by: All dashboards for profile display and user verification
       Features: Fetch user details, permissions, and account status

PUT    /api/auth/me/update/
       Purpose: Update user profile information
       Used by: Profile management sections in all dashboards
       Features: Update personal info, email, phone, address, password change
